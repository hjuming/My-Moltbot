## 📊 專案核心流程圖

### 1. 資料清洗流程

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 從 Supabase 讀取資料                                │
│  SELECT * FROM places WHERE category IN ('pet', 'dive')     │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 用 SerpApi 搜尋 Google Maps                         │
│  Query: "{店名} {地址}"                                      │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
                    ┌────┴────┐
                    │  找到？  │
                    └────┬────┘
                         │
           ┌─────────────┴─────────────┐
           │                           │
           ▼ YES                       ▼ NO
┌──────────────────────┐    ┌──────────────────────┐
│ Step 3a: 更新資料     │    │ Step 3b: 標記或刪除   │
│ - 座標               │    │ - verification_status │
│ - 地址               │    │   = "not_found"      │
│ - 電話               │    │                      │
│ - 評分               │    │                      │
└──────────────────────┘    └──────────────────────┘
           │                           │
           └─────────────┬─────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 4: 寫入 Supabase 並生成統計報告                        │
│  ✅ 更新：XX 筆  🗑️ 刪除：XX 筆  ⚠️ 失敗：XX 筆              │
└─────────────────────────────────────────────────────────────┘
```

### 2. 大內美食匯入流程

```
┌─────────────────────────────────────────────────────────────┐

                         │
                         ▼

│  - 電話：06 576 3509                                        │
│  - 評分：4 星 (119 則評論)                                   │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐

                         │

│  INSERT INTO places (name, category, metadata, ...)         │
└─────────────────────────────────────────────────────────────┘
```

### 3. Map WEDO 前端互動流程

```
┌─────────────────────────────────────────────────────────────┐
│  使用者開啟 https://map.wedopr.com                           │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 取得使用者地理位置 (Geolocation API)                │
│  lat: 23.xxx, lng: 120.xxx                                  │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 從 Supabase 讀取所有地點                            │
│  SELECT * FROM places                                       │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 3: 客戶端計算距離 (Haversine)                          │
│  distance = getDistanceFromLatLonInKm(user, place)          │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 4: 使用者篩選                                          │
│  - 選擇類別：美食 / 旅遊 / 潛水 / 寵物                       │
│  - 搜尋關鍵字                                                │
│  - 點擊標籤過濾                                              │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 5: 依距離排序並顯示                                    │
│  - 最近的 30 筆                                              │
│  - 點擊「載入更多」顯示下 30 筆                              │
└────────────────────────┬────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 6: 點擊卡片跳轉 Google Maps                            │
│  開啟 Google Maps App 查看詳細資訊                           │
└─────────────────────────────────────────────────────────────┘
```
