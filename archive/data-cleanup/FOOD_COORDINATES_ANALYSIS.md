## 🔍 根本原因

### 1. 資料來源問題

原始 CSV 檔案：`research/map/台南大內尋飽圖_GoogleMap匯入清單.csv`

```csv
編號,店名,地址關鍵字
1,大內豆菜麵,台南市大內區
2,阿榮牛肉湯,台南市大內區
3,大內橋頭麵店,台南市大內區
```

**問題**：
- ❌ 只有籠統地址「台南市大內區」
- ❌ 沒有詳細地址（街道、門牌號）
- ❌ 沒有座標資訊

### 2. Google Maps 商家資料缺失

這些大內小吃攤特性：
- 🏪 多為路邊攤、小型店面
- ❌ 未在 Google Maps 註冊商家
- ❌ 無法透過 Google Maps API 搜尋到

**測試結果**：
```
搜尋「大內豆菜麵 台南市大內區」 → 無結果
搜尋「阿梅羊肉 台南大內」 → 無結果
搜尋「阿雪黑輪 大內區」 → 無結果
```

## 💡 解決方案

### 方案 A：使用區域中心點（推薦）⭐⭐⭐

為所有「台南市大內區」的店家統一使用大內區的地理中心點。

**優點**：
- ✅ 可立即完成
- ✅ 符合實際情況（都在大內區內）
- ✅ 地圖可正常顯示

**缺點**：
- ⚠️  位置不精確（誤差可能 1-3 公里）

**實作**：
```python
# 台南市大內區中心點
DANEI_CENTER = (23.1183, 120.3569)

# 為所有缺座標的大內美食設定
UPDATE places 
SET location = 'POINT(120.3569 23.1183)'
WHERE category = 'food' 
  AND address = '台南市大內區' 
  AND location IS NULL
```
