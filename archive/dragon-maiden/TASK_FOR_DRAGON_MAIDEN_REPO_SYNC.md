## 🎯 重點提醒

### ✅ 你要做的

1. **保持 Telegram 通知清楚明瞭**
   - 有新增專案時，列出專案名稱和連結（最多 3 個）
   - 有移除專案時，列出專案名稱（最多 3 個）
   - **有最近更新的專案時，列出專案名稱、連結、更新時間（最多 3 個）**
   - 提供完整變動報告連結
   - 使用 emoji 讓訊息更清楚

2. **格式保持一致**
   - 專案清單要有「名稱、**最後更新**、簡介、連結」
   - 按字母順序排序
   - 時間格式統一

3. **追蹤專案活動**
   - 24小時內有更新的專案都要報告
   - 使用「X小時前」的格式

### ❌ 不要做的

1. **不要執行 Supabase 資料庫操作**
   - 會導致系統卡住
   - 這不是你的工作範圍

2. **不要處理超過資源限制的任務**
   - 你的記憶體限制是 2 GB
   - 不要讀取大量外部文件
   - 不要執行複雜的多步驟任務
   - 不要執行超過 5 分鐘的長時間任務

3. **不要更改檔案格式**
   - 表格結構固定
   - Markdown 語法不變

4. **不要在 Telegram 貼大量內容**
   - 最多顯示 3 個新增專案
   - 其他提供連結查看
